عندما يعثر منار على أداة ذكاء اصطناعي فإنه يحميها فوراً دون سؤال. تسرد هذه الصفحة ما يعنيه ذلك. وتعرض صفحة أدوات الذكاء الاصطناعي في لوحة التحكم القائمة الدقيقة لحاسوبك، ويطبع المثبّت القائمة نفسها عند انتهائه.

## القواعد التي يتبعها منار

- **النسخ الاحتياطي أولاً.** قبل تعديل ملف إعدادات أي أداة يحفظ منار الأصل.
- **كل شيء مدرج.** يظهر كل تغيير في مخرجات المثبّت وفي لوحة التحكم.
- **مفتاح لكل أداة.** إيقاف الحماية لأداة ما يستعيد نسختها الاحتياطية.
- **الإزالة تستعيد الكل.** إزالة منار تستعيد كل نسخة احتياطية وكل سر في خزنة الأسرار.

## ما الذي يعدّله منار، لكل أداة

يغيّر منار حتى ثلاثة أنواع من الإعدادات: ربطاً (hook) يسأل منار قبل أي إجراء، وخوادم MCP تُغلَّف لتمر طلباتها عبر بوابة منار، وعنوان API الأساسي للأدوات التي تقبله، ويمر حينها عبر بوابة على حاسوبك نفسه (`127.0.0.1:8480`).

| الأداة | ما يتغير | الملف المعتاد |
|---|---|---|
| Claude Code | ربط PreToolUse | `~/.claude/settings.json` |
| Claude desktop | تغليف خوادم MCP | `claude_desktop_config.json` في مجلد بيانات التطبيق |
| Cursor | ربط قبل أوامر الصدفة والقراءة وMCP، وتغليف خوادم MCP | `~/.cursor/hooks.json` و`~/.cursor/mcp.json` |
| Windsurf | ربط، وتغليف خوادم MCP | `~/.codeium/windsurf/` و`mcp_config.json` |
| VS Code مع GitHub Copilot | تغليف خوادم MCP | `mcp.json` في مجلد مستخدم VS Code |
| Copilot CLI | ربط، وتغليف خوادم MCP | `~/.copilot/` |
| Codex CLI | تغليف خوادم MCP وعنوان API الأساسي لتمر الطلبات عبر البوابة المحلية. لا ربط: يطلب Codex من مالكه مراجعة أي ربط جديد قبل تشغيله | `~/.codex/config.toml` |
| Gemini CLI | ربط، وتغليف خوادم MCP | `~/.gemini/settings.json` |
| ChatGPT desktop | لا شيء. يُرصد ويُنبَّه عنه فقط | لا يوجد |

المسارات هي المعتادة وقد تختلف على حاسوبك. وقد جرى التحقق من دعم الربط أداة بأداة، وتذكر صفحة [التغطية](/ar/docs/coverage) النتيجة. والأداة التي لا ربط لها تُرصد ويُنبَّه عنها، ولا تُوصف أبداً بأنها خاضعة للحوكمة.

## تغييرات منار الخاصة

- خدمة في الخلفية تشغّل برنامج جهاز منار.
- على ويندوز: متطلب WireGuard، وتفعيل سياسة تدقيق نظام الملفات (Audit File System) لنسب قراءات ملفات الأسرار إلى مصدرها.
- على لينكس: مراقبة الملفات على قائمة الأسرار عبر fanotify.
- ملفات برنامج منار ومجلد حالته، ومنه النسخ الاحتياطية لكل ما سبق.

## مراقب الأسرار

يراقب منار قائمة من ملفات الأسرار وينبّهك عندما تلمس أي أداة ذكاء اصطناعي، أو أي عملية أخرى، واحداً منها. ويذكر التنبيه الأداة والعملية ونوع الملف.

- `~/.aws/credentials` و`config`
- المفاتيح الخاصة في `~/.ssh/`
- `~/.azure` و`~/.config/gcloud` و`~/.kube/config` و`~/.docker/config.json`
- قواعد بيانات ملفات تعريف الارتباط وتسجيلات الدخول في المتصفحات
- ملفات `.env` ضمن مجلدات مشاريعك، تُكتشف عند التثبيت وتُعاد فحصها يومياً

على ويندوز يضع منار قيود تدقيق على هذه الملفات ويقرأ سجل الأمان. وعلى لينكس يستخدم fanotify. ولا يقرأ منار محتوى هذه الملفات ولا يرسله أبداً.

يعتمد الحجب على الأداة. الأدوات ذات الربط تُحجب أو يُوافَق عليها عبر الربط على كل الأنظمة. وعلى لينكس يستطيع منار أيضاً رفض القراءات الصادرة من عمليات الأداة نفسها، بينما تكتفي الطرفية التي تكتب فيها بالتنبيه، فتستمر أوامر git وssh وعمليات النشر الخاصة بك. وعلى ويندوز تقتصر الأدوات بلا ربط على التنبيه. وإذا تعطل المراقب فإنه يتوقف ويعرض المراقبة غير متاحة، ولا يجمّد حاسوبك أبداً.

## خزنة الأسرار

يمكنك التفعيل سراً بسر من صفحة الأسرار، وتُعرض عليك بعد أول تنبيه.

- **مفاتيح AWS** تنتقل إلى مخزن المفاتيح في نظام التشغيل، ويُستبدل `~/.aws/credentials` بإدخال يطلب المفتاح من منار عندما يحتاجه برنامج.
- **مفاتيح SSH الخاصة** تُحمَّل في وكيل SSH الخاص بالنظام ويُزال ملف المفتاح من القرص.

كل برنامج جديد يطلب سراً يسألك مرة واحدة: السماح مرة واحدة أو السماح لمدة 8 ساعات أو السماح دائماً لهذا البرنامج أو الرفض، ويُسجَّل جوابك. والاستعادة إلى الملف تتراجع عن ذلك تماماً، والإزالة تستعيد كل شيء أولاً.

ملفات `.env` ليس لها بروتوكول مساعد، لذلك تبقى للتنبيه فقط، باستثناء الأدوات والأنظمة المذكورة أعلاه. وبيانات اعتماد Azure وGoogle Cloud تأتي بعد الإطلاق.
