Manar is open core under the Apache-2.0 licence.

## What is open

The core is public in the [manarhq](https://github.com/manarhq) organisation on GitHub: the API, the web console, the device software (manar-edge), the agents and the website. Each repository has a LICENSE, a NOTICE, a SECURITY file and contribution notes.

## What is commercial

Hub and federation, AD and Entra sync, fleet management, compliance packs, air-gapped installs and TPM attestation are commercial. They are enabled by a signed licence.

## Contributing

We use the Developer Certificate of Origin. Sign off each commit with `git commit -s`. There is no CLA. Read CONTRIBUTING in the repository you want to change.

## Trademark

The name Manar and its mark are trademarks of Fixio. The Apache-2.0 licence covers the code, not the name. You may say your project works with Manar. Please do not name a product or service Manar, or suggest we endorse it.

## Reporting a vulnerability

Follow the SECURITY file in the repository. Please do not open a public issue for a vulnerability.

## Check what you install

Every release of the device software publishes a `SHA256SUMS` file. The installer checks it for you, and you can check it yourself.
